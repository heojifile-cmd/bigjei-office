# 빅제이 비서실 🏢

아이폰 사파리에서 **홈 화면에 추가**하면 주소창 없이 전체 화면 앱처럼 열리는 개인 현황판 페이지입니다.

- 🗺️ **오피스 맵** — 클레이 3D 오피스 그림에서 방(대회의실·지휘실·라운지)과 캐릭터를 눌러 상태 확인
- 💬 **회의실** — 방별 채팅과 `@멘션` (내용은 기기 localStorage에 저장)
- 📋 **작업실** — 진행 중인 작업 카드
- 📊 **비서현황** — 비서 4명의 담당 업무
- ⚡ **AI한도** — 자동 스케줄과 오늘 진행률
- 📝 **메모** — 빠른 메모 추가·삭제 (localStorage 저장)

## 아이폰에 앱처럼 설치

1. 사파리로 이 페이지를 엽니다.
2. 하단 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면의 👑 아이콘으로 실행하면 전체 화면으로 열립니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본체 (6개 탭, 채팅·메모 기능) |
| `map.jpg` | 클레이 3D 오피스 맵 이미지 |
| `icon.png`, `icon-180.png` | 홈 화면 아이콘 |
| `manifest.webmanifest` | 앱 설치 메타데이터 |

> 이 저장소는 공개 페이지입니다. 실제 개인 정보(금액·연락처·예약·병원 등)는 넣지 않고 예시 문구만 담았습니다. 채팅·메모는 서버로 전송되지 않고 보는 기기의 브라우저에만 저장됩니다.
